## 研究概述

在联邦大模型微调（FedLLM）场景下，利用聚合 LoRA 更新的乘积 ΔW = AB 的谱结构检测后门攻击并修复。

**核心论证链**（详见背景知识文献指南）：
- FLoRA：分量级聚合 E[A]·E[B] ≠ E[AB]，数学上不正确
- FedSA-LoRA：A 学通用知识 / B 学客户端特异知识
- GAP：攻击者可构造"单独良性、乘积恶意"的 A/B 对，乘积从不被验证 → 检测应在乘积层
