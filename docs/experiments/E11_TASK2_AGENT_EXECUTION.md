# E11 Task2 本地 Agent 执行说明

> 唯一执行依据：`docs/experiments/E11_TASK2_DESIGN.md`。执行前必须完整阅读该文件及本说明。不要参考旧 V2/V3 Prompt 拼接执行。当前代码入口尚未完成迁移前，禁止启动 GPU 正式训练。

## 重要执行补充：持续轨迹与同轮影子对照

不得将每轮都从正常全局轨迹 (G^N_{r-1}) 重新开始的结果误称为30轮持续联邦训练。必须分别实现：

1. **持续轨迹：** 00、U、10、01、11各自从共同的 (T_0) 开始，客户端每轮从本分支上一轮全局状态训练，服务器聚合结果成为本分支下一轮状态。U的第r轮上传必须从 (G^U_{r-1}) 重新训练；A/B的构造也必须使用对应分支当轮全局状态及当轮真实正常填充上传。
2. **同轮影子对照：** 在预先指定轮次，从同一个冻结参考全局状态生成00、U、10、01、11的同轮上传。正常上传必须相同，客户端位置和FedAvg权重必须相同。影子结果只用于同轮因果比较，不反馈到持续轨迹。
3. 每个持续轨迹和影子对照使用不同目录、不同manifest字段和不同结果表。禁止混合统计。
4. 四分支交互项 (I_Y) 的同轮因果估计必须来自同起点影子分支；持续轨迹另行报告跨轮累积差异。若要计算持续轨迹交互项，必须明确其为轨迹层面的差分，并使用相同种子、相同评价样本和配对统计。
5. 30轮训练必须保存每条轨迹每轮的起点全局哈希、客户端上传哈希、聚合结果哈希和下一轮起点哈希。断点恢复必须验证整条链。


## Agent 必须遵守的执行顺序

### 工作一：审计并建立唯一输入清单
1. 核对 Task1 的 (T_0)、30轮目标数据清单、sample_id、B_huayu_first 顺序、训练参数、模型文件和 SHA256。
2. 核对正常客户端数据分区、随机种子和每轮样本调度。
3. 核对 Task1 与 Task2 的 LocalTrainer、tokenizer、模型、LoRA、优化器、学习率、梯度累积、更新次数、序列长度和聚合代码。
4. 输出 machine-readable manifest。任何来源不明、哈希不符或配置差异必须停止。

### 工作二：实现正常全局轨迹与 U
每轮从 (G^N_{r-1}) 训练十个正常客户端，使用真实 FedAvg 得到 (G^N_r)。同一轮 U 也从 (G^N_{r-1}) 初始化，按 Task1 冻结的20条目标训练记录、sample_id 和消费顺序训练10步。

严禁把 Task1 的 (T_r) 直接当作 Task2 的 U 上传；严禁把 (T_{r-1}) 当作 Task2 全局起点；严禁用逆 FedAvg 反算 U。

实现并独立验证：
[
G^U_r=0.1U_r+0.1sum_{j=1}^{9}N_{j,r}
]
所有计算均逐模块分别处理 P/Q 因子，并执行仓库真实服务器聚合。

### 工作三：先验证 U，再评价检测器
先评价00正常聚合和U聚合。00未保持正常行为或U未达到强行为门槛时立即停止。通过后才允许拟合独立正常校准阈值并运行 Norm、Cosine、FoolsGold、CBDF。报告全部混淆矩阵指标、AUC、逐轮分数、客户端排名和误报率。检测器不得使用测试标签重新选阈值。

### 工作四：数学构造和离线搜索
按设计文档公式实现 D_P、D_Q、P_A、P_B、Q_A、Q_B。实现后先运行真实张量恒等式测试，再进行225组参数筛选。对每个候选计算有效 BA、P因子、Q因子三种更新尺度，并运行单支行为、联合行为和检测分数评价。

候选筛选只允许使用开发种子。留出种子不参与参数选择。缓存推理结果前必须证明缓存键包含模型哈希、输入哈希、分支和参数；最终选定参数必须重新执行真实11分支推理。

### 工作五：单支和联合验证
四分支必须从相同干净全局起点出发，使用同轮相同正常上传。分别评价00、10、01、11和U。10/01单支行为弱，11联合行为恢复，并且11的因子聚合结果与U聚合结果在规定误差内一致。

计算显式权重交互项和低秩交叉项，逐模块比较。行为交互按product_id配对、defect_type分层Bootstrap，报告95%置信区间。

### 工作六：检测与聚合防御
完整执行Norm、Cosine、FoolsGold、CBDF；Multi-Krum selected=8和selected=6；Trimmed Mean。报告每个客户端的检测结果、排除名单或坐标裁剪比例、聚合后行为。不得把坐标裁剪解释成整客户端排除。

### 工作七：测试、归档和报告
每个阶段保存：
- run_state.json；
- 输入、代码、配置和数据 SHA256；
- 每轮全局状态与客户端上传；
- 每轮样本消费清单；
- 真实服务器聚合输出；
- 逐提示评价结果；
- 检测分数、阈值和混淆矩阵；
- 阶段验收结果和失败原因。

恢复运行时必须核对文件哈希和实际内容。不得仅凭文件存在跳过阶段。禁止 mock、伪造数据、静默异常捕获、自动放宽验收条件或覆盖历史实验目录。
