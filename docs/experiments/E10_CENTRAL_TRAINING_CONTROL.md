# E10 集中训练参照模型替换与复评

## 本次研究问题

用与真实客户端相同的一轮训练预算，在服务器上集中训练普通任务参照模型，测量其适配器大小和任务表现。这里的“集中”指训练在服务器上一次完成。测试对象是拆分前的模型。本实验仅估计整套训练与数据条件改变后的结果，不单独估算各超参数的因果贡献。

已有 90 轮中正常提交均值为 0.9004。按同一批轮次加权，旧集中目标、截断后的目标、扣除背景后的乘积、最终上传分别为 4.6378、3.9841、6.5774、6.5116。扣除背景后平均增加约 65%。新实验使用第一轮的同轮正常提交作参照，重新计算旧模型在这些轮次上的倍数。不能直接用 90 轮总体均值代替第一轮分母。

## 训练对象与成本

使用 Dolly、PKU 各自的三个既有种子 17、42、2026。每个系列只训练一个新参照模型，各运行 10 个优化步，合计六次、60 步。初始化取该系列预定背景轨迹第一轮真实下发的完整适配器，记录文件哈希。即使初始乘积均为零，也要复用真实因子。Dolly 使用归档中共用的 clean_s2026 轨迹；PKU 在各自种子的测试角色轨迹中按轨迹名排序取第一条。训练前保存选择清单。

复用正常客户端的 LocalTrainer、分词、损失和已经生效的配置。核对 Qwen3-1.7B、r=8、α=16、有效批量 2、学习率 1e-4、权重衰减 0.01、当轮新建优化器。每组按种子从同来源普通训练池选取 20 条有效记录，来自现有 Dolly 或 PKU 正常训练集，与固定测试集隔离。保存所用记录编号、实际优化步数和参与损失的回答词元数。该对照只使用正常任务数据，原 E10 仓库判断题可以作为固定观察题。它不能证明旧反事实规则已保留。

## 替换与复评

在独立实验目录中生成系列到新适配器路径的映射，让评估入口按映射加载新模型。旧集中目标、八名正常客户端的上传和原实验结果保留作参照。加载后记下适配器哈希并核对它与训练产物一致。新模型直接训练为 r=8，无需再从 r=32 截断。

1. 大小。复用 norm_origin_audit 的计算函数。对同系列列出旧原始目标、旧 r=8 目标、新模型及同轮八个正常上传的大小。分别报告新旧模型相对同轮正常均值的倍数，并给出八人的范围。六个训练结果各占相同权重。Dolly 三组共用的正常背景须注明。
2. 能力。对训练起点、旧 r=8 目标、新模型使用同一组留出的普通指令题和同一评分程序。优先复用已有可核对的普通任务评测；若没有共同的确定评分，预先固定现有留出正常指令集，报告参考回答上每个有效回答词元的平均负对数概率，数值越低代表模型给参考回答的概率越高。报告题数、有效词元数和每个系列的结果。仓库判断题另列原有测试题的放行数与总数，不用作挑选参数的依据。
3. 复用。旧评分仅在模型、题目、评分程序和推理设置一致时直接引用。缺哪项只补评哪项。相同输入以哈希去重，作业完成后校验结果再记录完成状态。复用旧背景和审计数据，省去背景训练、90 轮拆分重建及 E11 评估。本次结论止于拆分前。
4. 解释。同时呈现大小与任务成绩。大小接近背景但普通任务退化，仍须报告；大小接近且普通任务持平，只支持普通任务参照模型的结论。历史反事实目标与新普通任务模型训练内容有别，不能把两者差异全部归给训练步数。

## 交付与执行提示词

输出目录为 reports/e10_central_training_control/。提交 RESULTS.md、逐系列 metrics.tsv、运行配置与哈希清单、可重复启动脚本。模型权重存入独立的 artifacts 子目录。RESULTS.md 写明实际训练次数、复用的项目、大小与成绩的变化及缺失材料。

给本地 Agent 的任务：读取本方案和 reports/e10_norm_origin_audit/training_comparison.tsv。在独立工作目录检出本方案分支，保留工作区已有修改。实现参照模型替换和评估入口，按本方案执行六个训练作业、复用已有评估、核查各系列数据后提交结果到本分支。报告每组新旧模型相对同轮正常客户端的倍数以及固定测试题成绩。材料不足时列出缺失路径，继续完成有材料的系列。如实记录失败或未验证项目。
