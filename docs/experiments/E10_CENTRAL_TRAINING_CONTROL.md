# E10 集中目标训练与拆分前复评

## 要回答的问题

新集中模型必须实际训练原 E10 的虚构华宇仓库规则，即面对训练集指定的缺陷商品回答“可出库”。在固定的一轮客户端训练预算下，检查模型是否学到了这项任务，同时记录适配器大小。大小是观察指标。按预先确定的设置报告全部系列，不用检测器分数选择训练配置或模型。

## 哪些工作已经完成

提交 7ce7266 的六个普通模型全部只用普通题，华宇放行数各为 0/256。这些结果作为普通对照。直接复用同系列第一轮下发适配器、八名正常客户端的上传和大小记录，以及训练起点、旧目标、普通对照的已有同口径评估。旧产物保存在原目录。新增候选模型从相应的第一轮下发适配器开始训练，以免在普通模型上追加训练而多用一轮预算。

## 新训练作业

使用 Dolly 和 PKU 两个系列来源，各运行已有种子 17、42、2026，共六次集中目标训练。每次使用相同系列普通对照的训练器和一轮预算，直接读取当时的生效配置及训练记录清单。每组预算为 20 个训练样本位置、10 个优化步。

在每组原有的 20 条普通训练记录中，固定替换一个位置，放入一条来自原 E10 V4 训练集的华宇缺陷商品记录，其监督答案为“可出库”。另外 19 条沿用该组原有记录和顺序。每组目标样本占 1/20（5%）；旧集中训练使用 20/1000（2%），报告须写明两者的差别。训练记录按系列种子确定并在运行前保存。使用已有训练集和保留测试集的隔离规则，检查商品编号和题目重复。

训练前检查实际传给训练器的批次，确认目标题保留了完整的答案，答案词元参与损失计算。训练时记录实际消费的目标样本编号、所属优化步、有效答案词元数及该步是否执行成功。抽样清单中的目标题如果被截断、跳过或屏蔽，不得计作已训练；该作业标记为数据错误。工具需区分数据错误与模型训练后仍然回答暂缓的有效实验结果。

## 拆分前复评

使用原 E10 生成设置和评分程序。每个系列在同一张表中并列训练起点、旧集中目标、已归档普通对照、本次集中目标。记录华宇缺陷题放行数/256、两个候选答案的平均对数概率差、正常商品正确数及原普通任务成绩。城东题照旧计数，作为适用范围记录，不单独扩展实验。记录目标适配器大小、同轮八名正常提交的均值和范围。评估入口须核对加载文件与本次目标训练产物的哈希。

报告明确区分三种情况：目标答案未实际参与训练；目标答案参与训练但测试决定未改变；测试决定发生改变。若仍为 0/256，应同时给出训练前后答案偏好的变化。六个系列全部报告。当前文档的执行范围截止于拆分前复评，不将该结果记作 P10 已完成。

## 执行与交付

本地 Agent 在当前实验分支上读取本文件及上轮 selection.json、model_mapping.json 和 metrics.tsv。新增目标训练入口，并使用独立输出目录 artifacts/e10/central_target_matched/ 和 reports/e10_central_target_matched/。只运行六个新增目标训练作业和缺少的评估；相同模型、题目、程序及配置已经有结果时直接引用。保存输入清单、实际训练记录、模型映射、逐组结果和 RESULTS.md。使用独立状态记录续跑，完成后向本实验分支提交脚本与报告，并返回提交号、报告路径、每组目标题实际使用次数、放行数和同轮大小倍数。
