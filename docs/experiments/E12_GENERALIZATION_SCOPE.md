# E12 泛化研究范围

**制定日期**：2026-11-26  
**状态**：研究方向备忘；暂不制定具体实验流程。  
**前置条件**：E11 Task 2 核心实验完成，并形成可复核的结果报告。

## 1. E12 的定位

E12 用于研究 E11 核心发现的适用范围。E11 先在一个固定实验环境中回答联合影响、单客户端影响和聚合前检测三个核心问题。E12 再根据 E11 的实际结果，选择值得进一步验证的变化因素。

E12 不提前假设 E11 的研究假设一定成立。若 E11 未能形成单弱合强效果，E12 应先围绕失败原因重新确定研究问题。

## 2. 后续可以研究的泛化方向

1. **随机种子变化**：检查核心现象能否在不同训练随机过程中重复出现。
2. **数据来源变化**：检查 Dolly 上的结果能否迁移到 PKU 等其他普通任务数据。
3. **客户端数据差异变化**：研究近似 IID、不同程度非IID条件下，正常客户端分数分布和检测误报率如何变化。
4. **因子构造比例变化**：研究核心实验选定比例附近的构造变化是否影响单客户端效果、联合效果和检测结果。
5. **客户端数量和参与比例变化**：研究正常客户端数量、拆分客户端数量及参与比例变化对因子聚合和检测的影响。
6. **检测方法适用范围**：研究 Norm、Cosine、FoolsGold、CBDF 以及现有聚合防御在不同实验环境中的表现差异。

当前不建立 E12 训练队列，不生成大规模实验配置，不预先分配 GPU 预算。

## 4. E12 启动条件

E11 完成后，依据真实结果回答：

- 核心联合效应是否成立；
- 单独客户端是否确实较弱；
- 联合结果是否接近未拆分参照；
- 现有检测方法是否出现稳定差异；
- 结果是否可能受到单一数据集、随机种子或数据划分的限制。

只有明确这些问题后，才制定 E12 的具体实验设计。
