# E12 泛化研究范围与后续设计记录

**版本**：1.1  
**制定日期**：2026-11-26  
**状态**：研究范围已记录；具体实验设计暂缓。  
**前置条件**：E11 核心实验完成，形成可复核的结果报告。  
**关联项目**：[FedLoRA-Guard](https://github.com/1376524890/FedLoRA-Guard)

## 1. E12 的研究定位

E11 的任务是快速验证核心研究路径：在联邦 LoRA 训练中，两个拆分客户端能否分别保持较弱的单独影响，在共同参与时形成明显联合影响；这种联合效果能否接近未拆分客户端；服务器现有聚合前检测方法能否识别或区分这些上传。

E12 负责研究 E11 结论的适用范围，回答核心现象在其他训练条件下能否重复，以及检测结果会受到哪些条件影响。

E12 的研究问题必须由 E11 的真实结果引出。当前不假设 E11 的联合效应、行为等价或检测差异一定成立。如果 E11 的核心假设没有得到支持，E12 应先根据失败证据调整研究问题，再决定是否开展泛化实验。

## 2. 与 E11 的边界

| 项目 | E11 | E12 |
|---|---|---|
| 主要目标 | 快速验证核心研究路径 | 研究核心发现的适用范围 |
| 数据环境 | Dolly | 根据 E11 结果选择 |
| 随机种子 | 核心实验固定 seed 17；复用正常轨迹辅助校准 | 根据需要增加 |
| 客户端数据差异 | 固定 Dirichlet α=5 | 根据需要改变 |
| 因子构造比例 | 依据预先规定的数学筛选规则确定一个 ε | 研究其他比例是否改变结论 |
| 训练规模 | 固定十个客户端、30轮 | 根据具体研究问题确定 |
| 实验流程 | 已在 E11 核心方案中冻结 | E11 完成后再制定 |

E12 不承担补跑 E11 未完成的核心训练任务。E11 的失败轮次、输入错误或实现缺陷应先在 E11 中查明和处理，不能通过扩大实验规模掩盖。

## 3. 候选泛化研究方向

以下内容是候选研究方向，不代表全部都必须执行。E11 完成后，依据结果选择有明确研究价值的方向。

### 3.1 随机种子变化

检查联合影响、单客户端影响和检测差异能否在不同训练随机过程中重复出现。重点关注结果方向、效应大小和检测排名是否稳定。

### 3.2 数据来源变化

检查核心现象能否从 Dolly 迁移到 PKU 等其他普通任务数据。需要区分数据内容、样本长度、任务类型和数据清洗方式可能带来的影响。

### 3.3 客户端数据差异变化

研究近似 IID、Dirichlet α=5、α=2 等客户端数据分布下：

- 正常客户端上传分数分布如何变化；
- 正常客户端误报率是否增加；
- 单独客户端和联合客户端的有效更新是否发生变化；
- 联合影响是否仍然成立。

### 3.4 因子构造比例变化

研究 E11 选定比例附近的其他 ε 是否改变：

- A、B 单独参与时的有效更新大小；
- 联合聚合后的目标恢复误差；
- 单客户端行为和联合行为；
- Norm、Cosine、FoolsGold、CBDF 等检测方法的结果。

### 3.5 客户端数量和参与比例变化

研究正常客户端数量、拆分客户端数量、客户端权重和每轮参与比例变化对因子聚合、联合效果和检测结果的影响。

### 3.6 检测方法适用范围

比较 Norm、Cosine、FoolsGold、CBDF，以及 Multi-Krum、Trimmed Mean 等现有方法在不同实验环境中的表现。重点区分客户端级检测、客户端组合识别和聚合后行为变化。

## 4. E11 完成后需要回答的问题

启动 E12 设计前，先整理 E11 的实际证据：

1. S-A、S-B 是否分别满足单客户端影响较弱的判定条件？
2. S-AB 是否形成明显联合效果？交互项及其置信区间如何？
3. U 与 S-AB 是否达到预先规定的行为可比性要求？
4. 选定 ε 下，A、B 的有效更新范数与正常客户端分布相差多少？
5. Norm、Cosine、FoolsGold、CBDF 是否识别出 U、A、B 或 A+B？误报率和召回率如何？
6. Multi-Krum 和 Trimmed Mean 的同轮影子回放是否改变聚合结果？
7. 哪些结论由数据直接支持，哪些仍受单一数据集、单一正式种子或特定客户端划分限制？

E12 的研究问题、实验规模和优先顺序必须由这些结果决定。

## 5. 后续实验设计的选择原则

- 每个实验只回答一个明确的泛化问题。
- 优先改变能够解释 E11 结果边界的因素。
- 保留 E11 的核心评价指标，使不同实验之间可以比较。
- 对数据集、随机种子、客户端划分和检测阈值分别记录来源及哈希。
- 根据实验单位和统计目标确定样本量，不能把同一训练轨迹中的多个轮次当作独立随机种子。
- 预先规定评价指标、统计方法和停止条件。
- 如需改变因子构造方法或检测算法，必须说明改变对应的研究问题及其必要性。

## 6. 当前明确不开展的工作

在 E11 核心实验完成并经过结果审查之前：

- 不建立 E12 训练队列；
- 不生成 E12 训练配置；
- 不启动 PKU、近似 IID、α=2 或额外随机种子的训练；
- 不批量训练其他 ε；
- 不提前开发新的检测器；
- 不预先分配 GPU 预算；
- 不把候选方向视为已经确定的实验任务。

## 7. E12 启动条件与交付

E11 核心实验完成后，先形成 E11 结果审查记录，再确定 E12 的具体研究问题和实验方案。

E12 正式启动前应补充：

- 研究问题和待检验假设；
- 选择该泛化因素的 E11 结果依据；
- 数据集、模型、客户端划分和训练配置；
- 对照组和评价指标；
- 样本量及统计分析方法；
- 计算资源预算；
- 可复现输入清单、执行入口和验收标准。

E12 最终交付应包括原始训练记录、逐轮上传、检测结果、统计分析、可视化报告和完整复现说明。
