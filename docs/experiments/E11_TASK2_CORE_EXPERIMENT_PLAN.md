## 1. 核心研究问题

E11 Task 2 只回答一条核心研究路径中的三个问题：

1. 能否构造两个客户端 A、B，使 A 单独参与时不能形成目标行为，B 单独参与时也不能形成目标行为，而 A、B 同时参与后形成明显的联合行为？
2. 在目标行为相同或接近的前提下，未拆分客户端 U 与拆分客户端 A、B 的上传，能否被现有聚合前检测方法区分？
3. 这种联合效果能否由 LoRA 因子聚合的数学关系解释，并且在真实多轮联邦训练中持续出现？

核心比较为：

- N：十个正常客户端。
- U：一个未拆分目标客户端和九个正常客户端。
- S-A：只有 A 参与，另一个拆分位置由正常客户端填充。
- S-B：只有 B 参与，另一个拆分位置由正常客户端填充。
- S-AB：A、B 同时参与，另外八个客户端正常。

研究假设允许得到支持、否定或证据不足三种结果。不得为了得到预期结论而调整训练数据、ε、阈值或评价规则。

## 4. 因子构造与 ε 的唯一选择规则

### 4.1 使用现有构造公式

固定客户端权重：

\[
p_a=p_b=0.1
\]

LoRA scaling：

\[
s=\frac{\alpha}{r}=2
\]

从同一轮八个正常背景客户端 client_02 至 client_09 计算：

这里的 A_bg、B_bg 表示八个正常客户端各自按0.1权重加总后的背景贡献，不是八个客户端因子的简单算术平均。

\[
A_{\mathrm{bg}}=0.1\sum_{j=02}^{09}A_j,\qquad
B_{\mathrm{bg}}=0.1\sum_{j=02}^{09}B_j
\]

目标参照适配器经过 Procrustes 坐标匹配：

\[
\widetilde A_t=RA_t,\qquad
\widetilde B_t=B_tR^\mathsf T
\]

其中 R 为正交矩阵，因此：

\[
\widetilde B_t\widetilde A_t=B_tA_t
\]

定义：

\[
\Delta A=\widetilde A_t-A_{\mathrm{bg}},\qquad
\Delta B=\widetilde B_t-B_{\mathrm{bg}}
\]

沿用仓库现有 construct_pair 实现：

\[
A_a=\varepsilon\Delta A,\qquad
B_a=(10-\varepsilon)\Delta B
\]

\[
A_b=(10-\varepsilon)\Delta A,\qquad
B_b=\varepsilon\Delta B
\]

联合聚合时，八个正常客户端各占0.1，A、B各占0.1：

\[
\begin{aligned}
A_{11}
&=A_{\mathrm{bg}}+0.1A_a+0.1A_b\\
&=A_{\mathrm{bg}}+\Delta A\\
&=\widetilde A_t
\end{aligned}
\]

同理：

\[
B_{11}=\widetilde B_t
\]

因此，在因子分别平均的条件下，联合聚合可以恢复目标参照因子。实际代码必须同时验证因子重构误差和完整 BA 矩阵误差，不能只检查范数。

### 4.2 单客户端更新为什么可能过强

相对背景因子乘积，A 的乘积变化为：

\[
B_aA_a-B_{\mathrm{bg}}A_{\mathrm{bg}}
=
\varepsilon B_{\mathrm{bg}}\Delta A
+(10-\varepsilon)\Delta B A_{\mathrm{bg}}
+\varepsilon(10-\varepsilon)\Delta B\Delta A
\]

B 的乘积变化为：

\[
B_bA_b-B_{\mathrm{bg}}A_{\mathrm{bg}}
=
(10-\varepsilon)B_{\mathrm{bg}}\Delta A
+\varepsilon\Delta B A_{\mathrm{bg}}
+\varepsilon(10-\varepsilon)\Delta B\Delta A
\]

两个单客户端更新都包含交叉乘积项。ε会同时改变两个因子的幅度和单客户端有效更新，不能只依据因子比例判断更新是否足够弱。

特别说明：

- ε=5 会令 A、B 两个客户端都使用5倍的 ΔA 和5倍的 ΔB，交叉乘积项系数为25。旧 P2 诊断已指出这种对称构造可能造成单客户端更新过大，因此不得直接将 ε=5 设为默认值。
- ε=0.1 的旧 P2 结果出现 A/B 因子注入明显失衡，也不得直接把它作为默认值。

### 4.3 只做一次低成本数学筛选

完整训练前，对以下候选值执行单轮数学计算：

\[
\varepsilon\in\{0.1,0.2,0.5,1.0,2.0,5.0\}
\]

六种比例在两个数学筛选环境中分别计算：

- Dolly α=5、seed42：使用对应初始化、目标参照本地更新和 N_dolly_s42_a5 第一轮八个正常背景客户端上传；
- Dolly α=5、seed2026：使用对应初始化、目标参照本地更新和 N_dolly_s2026_a5 第一轮八个正常背景客户端上传。

两个筛选环境都使用同一组商品题对、同一 B_huayu_first 排列和同一 Procrustes 规则。每个环境中的目标参照本地更新都从对应冻结初始化出发，使用18条普通任务和一组反事实题对执行10次优化更新。每个环境的八个正常背景客户端上传，均从对应 N 轨迹的第一轮记录中读取。

先在 seed42 和 seed2026 两个筛选环境中确定 ε。随后在 seed17 环境中，使用 N_dolly_s17_a5 第一轮八个正常背景客户端上传和真实目标参照本地更新，对选定 ε 进行一次独立的尺度复核。seed17 的尺度复核结果不得用于重新选择 ε。seed17 的目标参照更新同时作为 U 分支第一轮目标客户端上传，避免重复训练。

对每个 ε 必须计算：

1. Procrustes 正交误差；
2. 旋转前后完整 BA 矩阵相对误差；
3. A、B 联合因子平均后的重构误差；
4. A、B 各自相对当前全局模型的有效更新范数；
5. 八个正常客户端相对同一全局模型的有效更新范数；
6. 所有因子、矩阵和范数的有限数值检查。

有效更新统一使用：

\[
\Delta W_i=s(B_iA_i-B_gA_g)
\]

不得把完整适配器的 BA 范数当作相对全局模型的有效更新范数。

对每个筛选环境 s，定义八个正常客户端有效更新范数的中位数：

\[
m_N^{(s)}=\operatorname{median}_{j=02,\ldots,09}
\|\Delta W_j^{(s)}\|_F
\]

要求 m_N^{(s)} 大于0。对每个候选 ε 计算：

\[
J_s(\varepsilon)=
\max\left(
\left|\ln\frac{\|\Delta W_a^{(s)}(\varepsilon)\|_F}{m_N^{(s)}}\right|,
\left|\ln\frac{\|\Delta W_b^{(s)}(\varepsilon)\|_F}{m_N^{(s)}}\right|
\right)
\]

再计算两个筛选环境中的最坏值：

\[
J_{\mathrm{screen}}(\varepsilon)=
\max\{J_{s42}(\varepsilon),J_{s2026}(\varepsilon)\}
\]

选择 J_screen 最小的 ε；若数值相同，选择较小的 ε。只有完整矩阵重构误差不超过1e-5、范数为正且所有数值有限的候选值才参与选择。

该规则只依据预先冻结的数学重构和有效更新范数计算。不得使用检测器分数、最终测试结果或完整训练后的行为结果选择 ε。seed17 的尺度复核只用于报告选定 ε 在核心训练环境中的实际尺度，不得改变选择结果。

如果六种候选值全部无法通过数学重构检查，停止后续训练并报告构造失败。若最优 ε 的单客户端范数仍明显偏离正常客户端分布，保留这一事实并继续核心训练；最终不得声称已经实现更新大小匹配。

ε 一经选定，在 U、S-A、S-B、S-AB 的全部30轮中固定，不根据训练表现或检测结果重新选择。

## 7. 行为评价与研究假设判定

### 7.2 联合影响强

- Pair_exact 不低于80%；

- 城东、北港平均 Margin 小于0。

### 7.3 同轮交互项

只使用第一轮共同初始化、共同正常上传和共同目标参照更新，计算：

\[
I_H=Y_{11}-Y_{10}-Y_{01}+Y_{00}
\]

其中：

- Y00：N 条件华宇缺陷放行率；
- Y10：S-A 条件华宇缺陷放行率；
- Y01：S-B 条件华宇缺陷放行率；
- Y11：S-AB 条件华宇缺陷放行率。

强联合效应的预设门槛：

\[
I_H\geq0.70
\]

同时报告按商品 ID 配对的95%置信区间。该交互项只用于第一轮共同起点比较，不将不同全局状态下的 r30 结果直接代入同一个因果交互公式。

### 7.4 U 与 S-AB 的行为可比性

比较 U 和 S-AB 的：

- 华宇缺陷商品放行率；
- 城东、北港缺陷商品暂缓率；
- 正常商品正确放行率；
- Pair_exact；
- 各仓库 Margin。

预设等价范围为±5个百分点。只有主要行为指标的配对95%置信区间整体落在该范围内，才能报告具有行为等价证据。

如果 U 未达到目标行为门槛，或者 U 与 S-AB 不具有行为等价证据，则检测差异只能作为描述性结果，不能声称拆分改变了检测难度。

### 7.5 最终测试

锁定确认集每个条件评价1536条提示，保存逐提示输出、商品 ID、仓库、真实标签、模型答案、Margin和最终判定。

所有指标分别报告命中数、分母、比例和95%置信区间。放行、暂缓和其他输出分别计数。

## 8. 现有检测方法和聚合方法

只运行仓库已经实现的方法，不开发新检测器、不训练新的检测模型、不新增检测特征、不根据检测结果修改上传。

### 8.1 聚合前检测

| 方法 | 使用内容 | 主要结果 |
|---|---|---|
| Norm | 相对当前全局模型的有效更新范数 | 原始分数、阈值、误报和检出 |
| Cosine | 现有有效更新余弦距离定义 | 原始分数、阈值、误报和检出 |
| FoolsGold | 现有在线历史权重 | 原始权重、1-weight分数、排名和判定 |
| CBDF | 现有客户端组合检测实现 | 检测组合、组合身份正确率、组合召回率、误报组合 |

有效更新统一使用：

\[
\Delta W_i=\frac{\alpha}{r}(B_iA_i-B_gA_g)
\]

Norm、Cosine、FoolsGold 的二元判定阈值只使用正常轨迹校准，禁止使用 U、S-A、S-B、S-AB 的检测结果调整阈值。

### 8.2 正常阈值校准

复用：

- N_dolly_s42_a5；
- N_dolly_s2026_a5。

两条正常轨迹用于计算 Norm、Cosine、FoolsGold 的5%目标误报阈值。N_dolly_s17_a5 作为留出正常轨迹，评价实际误报率。三个种子共用同一冻结数据划分，因此属于独立训练运行，不属于独立数据集验证。

本次只报告5%目标误报阈值，不额外估计1%阈值。实际误报率必须使用真实分母计算，并报告置信区间。

CBDF 沿用原有组合识别规则，不增加新阈值。

### 8.3 聚合防御影子回放

只对已保存的同轮上传执行离线回放：

- Multi-Krum：固定 f=2、十客户端、选择8个客户端；报告 U/A/B 是否被选中及聚合后行为。
- Trimmed Mean：沿用现有两端各裁剪2个值的实现；报告聚合后行为和相对 FedAvg 的变化。

影子回放结果不反馈到下一轮全局模型。因此只能说明同轮上传在替代聚合方法下的结果，不能声称完成了替代聚合方法的长期多轮训练验证。

### 8.4 检测指标

Norm、Cosine、FoolsGold 报告：

- TP、FP、TN、FN；
- Accuracy、Precision、Recall、F1；
- FPR；
- ROC-AUC、PR-AUC；
- 原始分数、阈值和客户端排名。

CBDF 报告组合身份正确率、组合召回率和误报组合率。

Multi-Krum 报告客户端入选和排除频率，不计算客户端级 F1。Trimmed Mean 不产生客户端排除名单，只报告聚合结果。

N、U、S-A、S-B、S-AB 的检测历史必须分别保存。真实恶意标签只用于离线统计，不能传入服务器检测计算。

## 9. 统计分析规则

1. 商品行为使用商品 ID 配对统计，同一商品在不同仓库的提示必须保持配对关系。
2. 交互项使用商品级配对 Bootstrap，至少2000次重采样。
3. 30个训练轮次存在连续依赖，不能把30轮当作30个独立随机种子。
4. 检测器结果分别报告逐轮指标、完整轨迹汇总和轮次分块置信区间。
5. 只有正常误报率可比、行为效果可比的 U/S-AB 条件，才进行主要检测率差异比较。
6. 只有一个数据集、一个正式训练种子和一个客户端数据划分。本次结果属于核心机制验证，不能声称已经证明跨数据集、跨种子或跨非IID程度的普遍规律。

## 11. 停止条件与结果解释

- P0 输入哈希不一致：停止。
- P1 六种比例均不能完成数学重构：停止，不启动多轮训练。
- P1 选出的比例更新范数仍明显偏离正常客户端：保留记录，继续核心训练，但不得声称更新大小已经匹配。
- S-A 或 S-B 达到目标放行行为：单客户端影响弱的假设不成立。
- S-AB 未达到目标条件行为：联合行为构造失败。
- U 未达到目标条件行为：不能比较 U 与 S-AB 的检测难度。
- U 与 S-AB 行为不等价：只能报告检测分数差异，不能解释为拆分导致隐蔽性提高。
- 检测器没有表现出预期差异：如实报告，不能通过改变阈值或重新选择 ε 修饰结果。
- 所有失败结果、异常轮次和未通过指标都必须保留。

E11 核心实验结束后，才依据实际结果确定 E12 的泛化研究内容。E12 当前只保留研究方向，不在本文件中增加多数据集、多种子和多数据分布的具体执行流程。
