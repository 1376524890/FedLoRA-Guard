## 1. 研究目标

Task2 研究已经训练成功的目标 LoRA 更新，能否通过数学拆分分配给两个联邦客户端，使两个客户端单独参与时都无法形成目标行为，两个客户端共同参与时形成目标行为，并且两个客户端及其组合能够避开现有聚合前检测方法。

Task1 已经训练并交付目标模型。Task2 直接复用 Task1 的真实训练检查点和最终适配器，不再重新训练目标行为模型。

必须同时满足的核心条件：

1. **单独影响弱**：A 单独参与和 B 单独参与时，均不能形成目标仓库条件行为。
2. **联合影响强**：A、B 共同参与时，能够形成 Task1 已经验证的仓库条件行为，并且连续评分显示显著正向交互。
3. **检测规避**：在正常客户端误报率固定为5%的工作点下，U 单客户端上传能够被常规检测方法识别，A、B 单独上传和 A+B 组合均达到预先冻结的低检出率门槛。

检测规避属于实验成功条件。未达到检测规避门槛时，不得将实验判定为成功；必须如实报告实际检出情况和未通过的检测器。

本实验不要求 S-AB 与 U 的每一个模型参数逐元素相等，也不把精确恢复 U 作为独立研究成功条件。因子代数等式只用于核验拆分实现及服务器聚合计算。研究成功由 A/B 单独行为弱、联合行为强、正向行为交互和检测规避门槛共同判定。

## 6. 数学构造

### 6.1 符号

每轮当前全局 LoRA 因子：

\[
A_g,\quad B_g
\]

Task1 下一轮目标检查点因子：

\[
A_T,\quad B_T
\]

客户端权重：

\[
p=0.1
\]

正常客户端上传：

\[
(A_j,B_j),\quad j=0,\ldots,9
\]

所有计算按 LoRA 模块独立执行。

### 6.2 U：单客户端等效上传

U 与九个正常客户端 N_1 至 N_9 聚合后，得到 Task1 目标因子。由服务器因子 FedAvg 反算：

\[
\boxed{
A_U=\frac{A_T-p\sum_{j=1}^{9}A_j}{p}
}
\]

\[
\boxed{
B_U=\frac{B_T-p\sum_{j=1}^{9}B_j}{p}
}
\]

当 p=0.1 时：

\[
A_U=10A_T-\sum_{j=1}^{9}A_j
\]

\[
B_U=10B_T-\sum_{j=1}^{9}B_j
\]

U 上传的完整有效更新：

\[
\Delta W_U=s(B_UA_U-B_gA_g)
\]

U 的因子和有效更新大小必须记录。U 不需要满足正常客户端更新大小范围；U 是未拆分目标更新的检测基准。

### 6.3 A、B 拆分

使用 N_2 至 N_9 的真实上传作为八个正常背景客户端：

\[
A_{bg}=p\sum_{j=2}^{9}A_j
\]

\[
B_{bg}=p\sum_{j=2}^{9}B_j
\]

定义：

\[
D_A=A_T-A_{bg}-2pA_g
\]

\[
D_B=B_T-B_{bg}-2pB_g
\]

独立设置：

\[
\lambda_A,\lambda_B\in(0,10)
\]

构造 A：

\[
\boxed{
A_A=A_g+\lambda_A D_A
}
\]

\[
\boxed{
B_A=B_g+(10-\lambda_B)D_B
}
\]

构造 B：

\[
\boxed{
A_B=A_g+(10-\lambda_A)D_A
}
\]

\[
\boxed{
B_B=B_g+\lambda_BD_B
}
\]

A、B 的实际上传必须分别保存完整因子张量。禁止只保存有效 BA 矩阵，因为检测器需要读取真实因子上传。

### 6.4 联合因子聚合关系

A、B 与八个正常背景客户端联合聚合：

\[
A_{11}=pA_A+pA_B+A_{bg}
\]

代入：

\[
\begin{aligned}
A_{11}
&=p(2A_g+10D_A)+A_{bg}\\
&=2pA_g+D_A+A_{bg}\\
&=A_T
\end{aligned}
\]

同理：

\[
B_{11}=B_T
\]

这是构造公式的代数检查。必须保存因子误差和完整 BA 误差，但不把 S-AB 与 U 的逐元素参数相等设为独立研究成功条件。正式成功判定以仓库行为、交互效应和检测规避门槛为准。

### 6.5 四个分支

每轮使用同一个 G_{r-1} 和同一组 N_0 至 N_9：

| 分支 | client_00 | client_01 | client_02—client_09 |
|---|---|---|---|
| 00 | N_0 | N_1 | N_2—N_9 |
| 10 | A | N_1 | N_2—N_9 |
| 01 | N_0 | B | N_2—N_9 |
| 11 | A | B | N_2—N_9 |
| U | U | N_1 | N_2—N_9 |

00、10、01、11、U 必须使用相同的全局起点和相同的正常背景上传。各分支独立执行服务器因子聚合并保存聚合后的模型。

### 6.6 有效更新与因子变化

对任意客户端 X：

\[
N_X=
\sqrt{\sum_m
\left\|
s(B_{X,m}A_{X,m}-B_{g,m}A_{g,m})
\right\|_F^2}
\]

A 因子变化：

\[
F_{A,X}=
\sqrt{\sum_m\|A_{X,m}-A_{g,m}\|_F^2}
\]

B 因子变化：

\[
F_{B,X}=
\sqrt{\sum_m\|B_{X,m}-B_{g,m}\|_F^2}
\]

三个指标分别记录。正常参照使用同一轮正常客户端 N_0 至 N_9 对应指标的中位数。

A、B 的三个尺度分别要求处于正常客户端对应中位数的0.5至2倍。U 不适用该限制。

### 6.7 权重交互项

定义四分支聚合因子：

\[
A_{11}=A_{00}+\delta_A+\eta_A
\]

\[
B_{11}=B_{00}+\delta_B+\eta_B
\]

其中：

\[
\delta_A=A_{10}-A_{00},\quad
\delta_B=B_{10}-B_{00}
\]

\[
\eta_A=A_{01}-A_{00},\quad
\eta_B=B_{01}-B_{00}
\]

有效权重的二阶交互项：

\[
\boxed{
C_W=W_{11}-W_{10}-W_{01}+W_{00}
=s(\delta_B\eta_A+\eta_B\delta_A)
}
\]

必须同时计算显式 BA 结果和上述低秩交叉项结果，并检查二者误差。

### 6.8 行为交互项

逐商品、逐提示计算目标答案与相反答案的对数概率差：

\[
Y=\log P(\text{目标答案})-\log P(\text{相反答案})
\]

四分支连续评分交互：

\[
\boxed{
I_Y=Y_{11}-Y_{10}-Y_{01}+Y_{00}
}
\]

主要报告华宇缺陷商品的 I_Y，并分别报告城东、北港缺陷商品的 I_Y。

以 product_id 为抽样单位进行至少2000次配对 Bootstrap。华宇目标行为的交互项95%置信区间下界必须大于0。

同时计算二值放行率交互：

\[
I_H=H_{11}-H_{10}-H_{01}+H_{00}
\]

其中 H 表示华宇缺陷商品放行率。要求：

\[
I_H\geq0.70
\]

## 7. 参数筛选与检测规避选择

### 7.2 更新尺度约束

对 A、B 的有效更新范数、A 因子变化范数、B 因子变化范数分别计算相对正常客户端中位数的比值。

所有开发检查点均要求：

\[
0.5\leq \frac{q_{X,r}}{M_{q,r}}\leq2
\]

其中 X 为 A 或 B，q 分别为有效更新、A 因子变化、B 因子变化。

定义：

\[
J=
\max_{r,X,q}
\left|
\ln\frac{q_{X,r}}{M_{q,r}}
\right|
\]

要求：

\[
J\leq\ln2
\]

零范数、非有限数值、模块缺失或张量形状不匹配均直接判定候选不合格。

A、B 上传必须存在实质差异。不得接受 A、B 完全相同的对称构造。保存因子差异、有效更新差异和两者余弦相似度。

### 7.3 检测阈值

Norm、Cosine、FoolsGold 和 CBDF 使用正常客户端真实上传确定阈值。

- N_dolly_s42_a5、N_dolly_s2026_a5：检测阈值校准。
- N_dolly_s17_a5：旧正常轨迹留出核验。
- 新生成的 Task1 目标检查点同起点正常客户端上传：用于同轮正常误报复核。

目标误报率固定为5%。检测阈值在参数开发完成前冻结，不得根据 A/B 检测结果修改。

CBDF 的正常对照使用正常客户端组合，计算组合级误报率。

### 7.4 检测规避硬门槛

在5%目标误报工作点下，参数开发种子必须满足：

| 检测对象 | 硬性要求 |
|---|---:|
| U 的单客户端检出率 | Norm 或 Cosine 至少一种达到80% |
| A 的单客户端检出率 | Norm、Cosine、FoolsGold各不超过10% |
| B 的单客户端检出率 | Norm、Cosine、FoolsGold各不超过10% |
| A+B 组合检出率 | CBDF不超过10% |
| 正常客户端误报率 | 每种方法不超过5% |

如果 U 无法被 Norm 或 Cosine 至少一种稳定识别，则当前实验不能证明拆分相对未拆分提高了检测规避能力。

如果 A、B 或 A+B 超过检测率门槛，则检测规避阶段不通过。

## 10. 聚合前检测

检测方法固定为：

- Norm。
- Cosine。
- FoolsGold。
- CBDF。

所有方法必须使用真实客户端上传和对应轮次的当前全局模型。

| 方法 | 输入 | 必须保存 |

| Cosine | 完整有效 BA 更新 | 原始余弦、异常分数、阈值、判定 |
| FoolsGold | 真实因子增量及历史记录 | 历史长度、权重、异常分数、判定 |
