# Qwen3-0.6B 单任务联邦 LoRA 实验

在服务器的 fllora 环境和仓库根目录中执行。脚本使用仓库固定版本的 Qwen3-0.6B、PEFT rank-8 LoRA 和 Dolly 原始数据。默认从 CUDA 设备 0 串行训练两名客户端。

日常运行可从 `bash scripts/run_abc.sh` 选择菜单 **9**，或直接调用：

```bash
bash scripts/run_abc.sh --qwen-lora-interaction --plan
bash scripts/run_abc.sh --qwen-lora-interaction
```

启动器询问批次名、原始数据路径、CUDA 编号、种子、数据量、训练轮数、优化步数及两个判定阈值。带 `--plan` 时只显示计划。训练中断后，用 `bash scripts/run_abc.sh --resume artifacts/abc/<批次名>` 沿用原计划，已完成的种子直接读取结果，未完成的种子复用已有客户端检查点。实验结果写入批次目录下的 `qwen_lora_interaction/`。

也可以直接调用 Python 模块：

```bash
conda activate fllora
python -m src.benign.qwen_lora_interaction \
  --output artifacts/abc/qwen_lora_interaction_01 \
  --equivalence-margin 0.01 \
  --joint-threshold 0.05
```

命令中的阈值是示例，单位为 nat/token。请按你认可的最小实际效应确定两个阈值，再执行实验。默认三个训练种子，每个种子首次微调和每轮后续微调均为每客户端 10 个优化步，合计 **90 次客户端训练、900 个优化步、6,144 次单样本评分前向**。预计剩余训练时间按已经完成的客户端训练计时更新。项目训练器逐优化步保存检查点，需要为这批检查点留出磁盘空间。输出目录须是仓库内的新目录。

## 单任务和对照

所有分支都只训练和评价 Dolly 摘要。脚本按固定种子抽取互不重叠的首次训练分区、继续训练分区和留出题，使用同一个提示及参考摘要评价各分支。每个训练种子内，两名客户端从相同的 Qwen LoRA 初始化出发，分别在自己的首次训练分区上微调并上传。

| 起点 | 首次聚合或初始化方法 |
| --- | --- |
| `00` | 两个位置均使用原始全局适配器 |
| `10` | 仅 A 位置使用客户端上传，B 位置保留原始适配器 |
| `01` | 仅 B 位置使用客户端上传，A 位置保留原始适配器 |
| `11` | 两个位置都使用客户端上传 |
| `local_a`、`local_b` | 直接使用单个客户端的完整上传，检查单独贡献是否被等权平均稀释 |
| `11_minus_initial_cross_term` | 从 `11` 出发，训练和评分的每次前向都减去相同的首次聚合交叉项 |

四个主分支的首次聚合始终使用两个等权位置。首次聚合后先评分，然后每个起点独立继续联邦训练。所有分支每轮收到相同的客户端数据和训练预算，使用相同的客户端种子和样本顺序。后续每一轮的 FedAvg 输出作为本分支下一轮的全局适配器。最终对同一批留出摘要复测。主对照衡量是否需要两个首次更新共同构成继续训练的起点。首次联合分支包含两个分区的信息，剂量和数据覆盖的独立效应需要其它实验才能识别。

## 结果判定

每个留出摘要用教师强制的每监督 token 平均 NLL 评分，包含 EOS。先配对计算每道题的效应，再对题目等权平均。定义收益为基线 NLL 减去分支 NLL。

- 单独效应弱要求区间完整落在等效界值内。首次阶段同时检查两份完整客户端上传；最终阶段同时检查两条等权单人分支和两条以完整客户端上传为起点的分支。
- 若首次聚合时主分支均在等效界值内、最终两个单独效应仍弱、联合收益下界超过阈值，而且联合模型的绝对 NLL 下降、相对同期 `00` 的收益增长，批次才报告支持「合并之后继续微调才出现收益」。
- 超加性单独检查 `联合收益 − A 收益 − B 收益` 的区间下界是否大于零。
- 交叉项检验对每个 LoRA 模块在 `11` 的训练和评分前向中减去固定的首次交叉项。该对照继续训练同秩的可训练 LoRA 因子，固定修正使用独立的低秩乘积表示，避免截断误差。最终比较两条轨迹的留出 NLL，估计固定修正干预的作用。
- 区间在每个训练种子内按留出题配对 bootstrap，并对该种子的全部对比做 Bonferroni 调整。批次要求指定种子均通过各自判定。区间描述固定训练条件下的留出题不确定性，跨训练分区和跨训练家族的泛化仍需额外研究。

`protocol.json` 保存实际配置和阈值，`s<seed>/manifest.json` 保存分区及模型身份，`s<seed>/results.json` 保存逐题分数、对比、区间及判定，`summary.json` 汇总各个种子。消融分支的最终有效模型由 `final_adapter.safetensors` 和 `fixed_cross_term.safetensors` 共同定义，仓库实验入口在评分时应用相同的固定修正。
